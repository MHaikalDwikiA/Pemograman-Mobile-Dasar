2.1 Urgensi Perancangan Sebelum Tahap Koding (The Blueprint Phase) 
Dalam proyek rekayasa perangkat lunak mobile industri skala menengah hingga besar, memulai

integrasi antarmuka). Perancangan blueprint menjamin setiap pengembang memahami kontrak data, 
batas tanggung jawab antarlapisan, dan alur aliran data yang sama.

💡 NILAI STRATEGIS OFFLINE-FIRST DALAM LOGISTIK: Pola Offline-First memastikan kurir di 
lapangan dapat terus bekerja menandai paket terkirim atau gagal kirim meskipun sedang berada di basemen 
gedung atau daerah pelosok tanpa sinyal seluler. Data tersimpan aman di persistensi lokal dan otomatis 
disinkronkan ke server pusat saat koneksi internet kembali pulih. 
2.3 Efisiensi Jetpack ListAdapter & DiffUtil vs Adapter Konvensional 
Pada implementasi RecyclerView konvensional, pembaruan daftar data sering kali memanggil 
metode notifyDataSetChanged(). Metode usang ini memaksa seluruh item di layar digambar ulang 
dari nol, menimbulkan kedipan layar (flickering), konsumsi baterai boros, serta lag scrolling (jank). 
Sebaliknya, Jetpack ListAdapter dengan DiffUtil menghitung selisih matematis antara daftar lama 
dan baru di Background Thread (menggunakan algoritma Eugene Myers) dan hanya memperbarui 
elemen sel yang benar-benar mengalami perubahan data.

Langkah 6.2: Prosedur Build Release APK Resmi 
Mahasiswa dapat memproduksi berkas APK rilis menggunakan dua metode: 
• Metode 1 (Command Line Interface): Buka Terminal di Android Studio, lalu jalankan 
perintah: `./gradlew assembleRelease`. Sistem Gradle akan menjalankan task KSP/kompilasi 
Kotlin, R8 shrinking, dan merilis file APK. 
• Metode 2 (Android Studio GUI): Pilih menu Build à Generate Signed Bundle / APK à Pilih 
APK à Buat KeyStore Baru (.jks) à Pilih Build Type 'release' dengan signature V1 & V2 à 
Klik Create. 
📦 LOKASI BERKAS OUTPUT PRODUKSI: Berkas APK produksi yang berhasil di-build terletak di path 
direktori: app/build/outputs/apk/release/app-release.apk (atau app-release-unsigned.apk). Ukuran berkas hasil 
minifikasi R8 umumnya berkurang 40% - 60% dibandingkan APK mode debug!
