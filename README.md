# 📱 Pemrograman Mobile Dasar

Repository ini berisi kumpulan tugas, praktikum, dan proyek latihan untuk mata kuliah **Pemrograman Mobile Dasar**. Setiap modul materi dan studi kasus dikelola secara terpisah melalui *branch* agar kode tersusun secara terstruktur.

---

## 🧭 Daftar Modul & Branch

Silakan beralih ke *branch* yang sesuai untuk melihat implementasi kode sumber masing-masing modul:

| No | Modul / Topik | Branch | Deskripsi |
| :---: | :--- | :--- | :--- |
| 1 | **NavigasiActivity** | [`NavigasiActivity`](../../tree/NavigasiActivity) | Implementasi Navigasi berbasis Android. |
| 2 | **Local Storage** | [`BelajarStorage`](../../tree/BelajarStorage) | Implementasi penyimpanan data lokal di Android. |
| 3 | **Kurir Directory App** | [`Kurir-Directory-App`](../../tree/Kurir-Directory-App) | Proyek direktori kurir berbasis Android. |
| 4 | **Logistics Tracker App** | [`LogisticsTrackerApp`](../../tree/LogisticsTrackerApp) | Proyek direktori pencarian id barang dan kurir berbasis Android. |
| 5 | **Fintech Billing App** | [`FintechBillingApp`](../../tree/FintechBillingApp) | Implementasi tampilan pembayaran berbasis Android. |
| 6 | **Smart Retail POS** | [`SmartRetailPOS`](../../tree/SmartRetailPOS) | Error handling & Teknik Debugging Aplikasi Mobile. |
| 7 | **Transport Booking QA** | [`TransportBookingQA`](../../tree/TransportBookingQA) | Pengujian Aplikasi Mobile & Penajaminan Mutu (QA). |
| 8 | **Fleet Track Pro** | [`FleetTrackPro`](../../tree/FleetTrackPro) | Perancangan Blueprint Arsitektur. |

## 🛠️ Prasyarat & Perangkat Pengembangan

Untuk menjalankan proyek-proyek di dalam repositori ini, pastikan sistem Anda memenuhi spesifikasi berikut:

- **IDE:** Android Studio Ladybug / Koala (atau versi terbaru)
- **Bahasa Pemrograman:** Kotlin / Java
- **JDK:** OpenJDK 17 atau lebih baru
- **Build System:** Gradle (Kotlin DSL / Groovy)
- **Minimum SDK:** Android API Level 24 (Android 7.0 Nougat) atau lebih tinggi
