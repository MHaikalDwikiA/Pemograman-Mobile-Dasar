2. TEORI PENGANTAR: STRUKTUR DATA JSON & ENGINE PARSER ANDROID 
2.1 Mengapa Pemodelan Data Transfer Object (DTO) Krusial? 
JSON (JavaScript Object Notation) adalah format pertukaran data standar web dan mobile 
berbasis teks biasa (String). Ketika aplikasi mobile menerima payload JSON dari server, teks 
mentah tersebut harus diuraikan (parsed/deserialized) menjadi representasi objek memori yang 
dikenali oleh bahasa pemrograman Kotlin. 
Di Kotlin, pemodelan ini diwujudkan melalui Data Class DTO. Keuntungan utama Data Class 
mencakup otomatisasi pembuatan fungsi equals(), hashCode(), toString(), dan copy( ) secara 
otomatis di balik layar oleh compiler Kotlin.

    class ViewHolder(view: View) : RecyclerView.ViewHolder(view) {

        val tvQtyPrice: TextView = view.findViewById(R.id.tvItemQtyPrice) 
        val tvSubtotal: TextView = view.findViewById(R.id.tvItemSubtotal) 
    } 
 
    override fun onCreateViewHolder(parent: ViewGroup, viewType: Int): ViewHolder { 
        val view = LayoutInflater.from(parent.context) 
            .inflate(R.layout.item_invoice_product, parent, false) 
        return ViewHolder(view) 
    } 
 
    override fun onBindViewHolder(holder: ViewHolder, position: Int) { 
        val item = items[position] 
        holder.tvName.text = item.itemName 
        holder.tvQtyPrice.text = "${item.qty} x @ ${rupiahFormat.format(item.unitPrice)}" 
        holder.tvSubtotal.text = rupiahFormat.format(item.subtotal) 
    } 
 
    override fun getItemCount(): Int = items.size 
}

5. TROUBLESHOOTING UMUM & TIPS DEBUGGING 
Jika mahasiswa menemui galat ketika melakukan parsing JSON, periksa penyebab dan solusi 
berikut: 
• 1. Field Objek Bernilai Null Meskipun Ada Datanya di Server: Penyebab: Nama variabel 
di Kotlin berbeda dengan nama kunci JSON server dan lupa menambahkan anotasi 
@SerializedName. Solusi: Tambahkan anotasi pemetaan tepat di atas variabel. 
• 2. java.lang.NumberFormatException: Penyebab: Server mengirim nilai desimal berkoma 
dalam bentuk teks bertanda kutip (contoh: "unit_price": "75000.0"), namun model DTO 
didefinisikan sebagai Int. Solusi: Gunakan tipe Double atau String. 
• 3. com.google.gson.JsonSyntaxException: IllegalStateException: Penyebab: Kunci 
summary pada server tidak dikirim atau bernilai null, sementara di Kotlin didefinisikan 
sebagai non-null. Solusi: Berikan tanda tanya (val summary: BillingSummary?) dan 
sediakan nilai fallback. 
• 4. Seluruh Field Berubah Bernilai Null Saat Build APK Release: Penyebab: Saat build 
release (minifyEnabled true), ProGuard mengaburkan (obfuscate) nama properti kelas. 
Solusi: Tambahkan -keepclassmembers class com.industri.fintechbilling.** { *; } pada 
proguard-rules.pro.

6. TUGAS MANDIRI PRAKTIKUM  
Untuk menguji penguasaan materi parsing JSON berstruktur, selesaikan tugas berikut: 
• Tugas 1 (Defensive Nullable Handling): Tambahkan properti opsional 'voucher_code: 
String?' dan 'voucher_discount_percent: Int?' pada BillingSummary yang bersifat nullable. 
Jika server tidak menyertakan voucher (bernilai null), sembunyikan baris diskon pada UI 
faktur dan tampilkan keterangan 'Tidak menggunakan promo'. 
• Tugas 2 (Custom Date Formatting): Buat fungsi ekstensi Kotlin atau Custom TypeAdapter 
untuk memformat teks tanggal transaksi ('2026-09-23 10:15:00') menjadi format waktu 
ramah pengguna: 'Rabu, 23 September 2026 - Pukul 10:15 WIB'.
